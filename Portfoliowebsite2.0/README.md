Arter-inspired Portfolio Boilerplate

Dieses Verzeichnis enthält ein minimal lauffähiges Boilerplate für das "Arter"-inspiriertes Portfolio.

Struktur:
- index.html
- css/styles.css
- js/main.js
- icons/*.svg
- assets/ (keine Bilddateien enthalten)

Kurzanleitung:
- Öffne `index.html` im Browser oder nutze einen Live-Server.
- Inhalte in `index.html` anpassen (Name, Links, Projekte).
- Assets (hero-bg, project thumbs, CV) in `arter-portfolio/assets/` ablegen.

Optional: Wenn du möchtest, verschiebe die Dateien ins Workspace-Root (`index.html`, `css/`, `js/`, `icons/`).
